# ItuStore 🛒

Sitio web de una tienda de computación desarrollado con *HTML, CSS y JavaScript*. Incluye un catálogo de productos, carrito de compras y una simulación del proceso de compra.

## Funcionalidades

- Catálogo de 15 productos con imágenes, descripciones y precios en pesos argentinos.
- Visualización de descuentos, cuotas y stock.
- Carrito con cálculo de totales y almacenamiento en el navegador.
- Simulación de compra con selección de método de pago, banco y cuotas.
- Formulario de contacto conectado a Formspree.
- Diseño adaptable a dispositivos móviles.

## Tecnologías

- HTML5 y CSS3.
- JavaScript.
- Bootstrap 5 y Bootstrap Icons.
- LocalStorage.
- Formspree.

## Cómo ejecutarlo

1. Clonar o descargar este repositorio.
2. Abrir index.html en el navegador.

No requiere instalar dependencias. Se necesita conexión a Internet para cargar los recursos externos y utilizar el formulario de contacto.

## Estado del proyecto

El proceso de compra es una demostración: no procesa pagos reales, no guarda pedidos en un servidor ni envía correos de confirmación.

Existe un problema conocido al mostrar el comprobante: se actualiza el modal del carrito en lugar del modal de pago.
